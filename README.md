# HR-Analytics-Dashboard

## 📌 Project Overview

This project presents an **HR Analytics Dashboard** developed to analyze employee data and uncover insights related to **attrition, workforce demographics, salary distribution, job roles, and trends over time**. The dashboard helps HR teams and management make **data-driven decisions** to improve employee retention and workforce planning.

The project uses an HR dataset and visualizes key metrics through an interactive dashboard.

---

## 🎯 Objectives

* Analyze employee attrition patterns
* Identify high-risk groups based on age, salary, job role, and gender
* Track attrition trends over time
* Provide an interactive and user-friendly HR analytics solution

---

## 📂 Dataset Information

The dataset contains employee-level HR data, including:

* Employee demographics (Age, Gender)
* Job-related attributes (Department, Job Role)
* Salary information
* Attrition status
* Years at company

**Dataset file:
- <a href="https://github.com/eshita100/HR-Analytics-Dashboard/blob/main/HR_Analytics.csv">Dataset</a>

## 📊 Dashboard Features

### 🔢 Key KPIs

* **Total Employees:** 1470
* **Attrition Count:** 237
* **Attrition Rate:** 16%
* **Average Age:** 37

---

### 📈 Visual Analysis Included

* **Attrition by Age Group** – Identifies age ranges with the highest attrition
* **Attrition by Gender** – Male vs Female attrition comparison
* **Attrition by Job Role** – Highlights roles with high employee turnover
* **Attrition by Salary Range** – Shows how salary impacts attrition
* **Attrition Trend by Year** – Tracks attrition changes over time
* **Department & Gender Filters** – Enables interactive data exploration
